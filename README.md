# Anahuac: The Sun's Debt - test builds

This page only holds test builds of the game for Windows. The game's source code is kept elsewhere.

## Download and play

1. Open **[Releases](../../releases)** (on the right of this page) and pick the newest build at the top.
2. Under **Assets**, click the `Anahuac_Windows_....zip` file to download it (about 600 MB).
3. Unzip it anywhere, open the `Anahuac` folder and run `Anahuac.exe`. If Windows shows "Windows protected your PC", click **More info** and then **Run anyway**.
4. Read `How to play.txt` in the same folder for controls, the story so far and how to play together.

You don't need a GitHub account to download.

## Playing together

At the bottom of the start screen, one player clicks **Host a group** and sends the 6-letter group code to the others, who type it into the **Group code or address** box and click **Join**. You need an internet connection; no router setup is needed.

## Reporting problems

Tell the team (or open an issue on this page) about crashes, getting stuck, falling through the ground, quests that won't advance, and anything confusing. Say what you were doing just before. After a crash, send the newest `Anahuac.log` from `Anahuac\Saved\Logs\`.

These are early development builds: expect bugs, and expect saved characters to be reset now and then.
